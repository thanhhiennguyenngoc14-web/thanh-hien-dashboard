# Góc làm việc của Thanh Hiền

Trang web tĩnh cá nhân. Tệp xuất bản là `index.html` ở thư mục gốc.

## Xuất bản bằng GitHub Pages

Trong repository trên GitHub, mở **Settings → Pages**. Chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/(root)`, rồi lưu. GitHub Pages sẽ phục vụ `index.html` từ thư mục gốc.

Các trường chưa được cung cấp vẫn để trống trong trang.
